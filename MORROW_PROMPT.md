# Prompt: MORROW — production-ready editorial website

Создай **полностью готовый к просмотру responsive website MORROW** — премиальное русскоязычное медиа для мужчин о современной, насыщенной и осмысленной жизни.

В качестве **главного визуального референса используй приложенное изображение**. Не переосмысливай его в generic SaaS / dashboard / startup-стилистику. Нужно максимально точно перенести ощущение референса: editorial luxury, журнальная верстка, сочетание светлого контента и тёмных cinematic-блоков, крупная типографика, качественная фотография, много воздуха.

Сайт должен выглядеть как **реальный запущенный digital magazine**, а не как UI-концепт, лендинг или шаблон.

## 1. BRAND

Название:

**MORROW**

MORROW — современное русскоязычное медиа преимущественно для мужчин 25–45 лет.

Мы не используем риторику:

- «стань лучшей версией себя»;
- «успешный успех»;
- «будь настоящим мужчиной»;
- «прокачай себя»;
- alpha male;
- токсичную продуктивность;
- инфобизнес.

MORROW — это редакционный фильтр.

Мы находим действительно интересные исследования, идеи, события, книги, интервью и изменения в мире и объясняем читателю главное.

Основная идея:

**Меньше информационного шума. Больше того, что действительно стоит времени.**

# 3. VISUAL DIRECTION

Максимально ориентироваться на приложенный референс.

Общее ощущение:

**Monocle × Esquire × Kinfolk × premium contemporary men's magazine.**

Не копировать конкретные бренды или их элементы. Использовать это только как уровень арт-дирекшна.

### Цвета

Основной фон:

**warm ivory / off-white**, приблизительно `#F4F1EA`.

Основной текст:

почти чёрный `#111111`.

Dark sections:

`#0D0F10` / `#111315`.

Дополнительные:

warm gray, stone, muted beige.

Не использовать:

- яркие gradients;
- neon;
- синие SaaS-акценты;
- glassmorphism;
- чрезмерные shadows;
- разноцветные карточки.

### Типографика

Ключевая особенность дизайна — сочетание **editorial serif + neutral sans-serif**.

Для крупных заголовков использовать элегантный editorial serif уровня:

**Cormorant Garamond / EB Garamond / Libre Baskerville / аналогичный доступный serif.**

Для интерфейса и основного текста:

**Inter / Manrope / Helvetica-like sans-serif.**

MORROW должен быть набран serif-логотипом с увеличенным letter-spacing.

Большие заголовки — serif.

Навигация, metadata, категории, даты — sans-serif.

Не использовать чрезмерно bold typography.

# 21. SOURCE POLICY

Каждая factual статья должна иметь источники.

Внизу:

**Источники**

Название источника
организация
дата
ссылка

Для важных утверждений желательно использовать primary source.

Не выдавать корреляцию за причинность.

Если исследование небольшое или предварительное — прямо это писать.

Если информация спорная — показывать uncertainty.

# 22. ЕСЛИ НЕТ WEB ACCESS

Это принципиально важно:

**НЕ ЗАПОЛНЯТЬ ПРОБЕЛЫ ВЫДУМАННЫМИ ДАННЫМИ.**

Вместо этого:

- использовать только подтверждённые данные, доступные системе;
- либо показывать редакционный placeholder;
- либо помечать блок как `Content pending verification`.

Никогда не создавать правдоподобную фиктивную новость только ради заполнения дизайна.

# 23. EDITORIAL STYLE

Все материалы писать на хорошем современном русском.

Стиль:

- интеллектуальный;
- спокойный;
- уверенный;
- конкретный;
- без снобизма;
- без канцелярита;
- без инфобизнеса;
- без AI-style filler.

Избегать заголовков:

**«7 невероятных способов...»**

**«Учёные шокированы...»**

**«Эта привычка изменит вашу жизнь...»**

Предпочитать:

**Что на самом деле известно о холодном душе**

**Почему после 30 становится сложнее поддерживать дружбу**

**Как AI меняет работу руководителя**

**Что стоицизм может дать человеку в 2026 году — и чего не может**
